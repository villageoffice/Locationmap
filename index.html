Help

Document

  • Type with your normal keyboard (Malayalam keyboard, voice typing or any language).
  • Drawing button: opens the drawing studio. When you press Insert the drawing is placed in the page. Tap it to edit, resize, align or delete; double-click to re-open the studio.
  • Menu → New location map: starts a full A4 sketch page straight away.

Saving

  • Auto-save: everything is saved in this browser as you type.
  • Save (Ctrl+S): save now. Save as file (Ctrl+Shift+S): download a .docstudio.json file that keeps drawings editable. Open file (Ctrl+O) opens it again, also on another device.
  • Version history: automatic restore points. If the drawing studio is closed by accident, you are asked to recover the drawing next time.

Drawing studio

  • Pick a tool on the left (bottom on phones) and drag. For roads and polylines tap each bend, then double-tap / Enter / tick to finish.
  • Bend rounds the corners (set R). Centre line adds a dashed middle line on roads.
  • Select: tap, drag a box, or Shift/Ctrl+tap for many. Blue handles resize, the round handle rotates. Group keeps items together.
  • Double-tap: edit text, symbol name, or the points of a line.
  • Keys: V select · H pan · T text · E erase · R rotate 90° · Ctrl+Z / Y undo / redo · Ctrl+D duplicate · Ctrl+G group · Ctrl+A select all · Del delete · Space+drag pan · Alt = no snap · Shift = straight / 45°.
  • Zoom with the mouse wheel or a two-finger pinch. On a computer the Layers tab (right) lists every object: click to select, lock or delete.
